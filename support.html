Questions fréquentes

Je n'entends pas la prononciation des lettres.
L'app utilise la voix arabe de ton téléphone. Sur iPhone : Réglages → Accessibilité → Contenu énoncé → Voix → Arabe, puis télécharge une voix. Les récitations du Coran, elles, fonctionnent sans réglage (connexion internet nécessaire).

Comment ne pas perdre ma progression ?
Elle est enregistrée automatiquement sur ton appareil. Pour la garder en lieu sûr ou la transférer sur un autre téléphone : Profil → Sauvegarde → « Copier mon code », puis « Restaurer depuis un code » sur le nouvel appareil.

Comment régler l'entraînement infini ?
Accueil → carte « Entraînement infini » → « Personnaliser » : contenu, lettres, niveau, vies et chrono.
